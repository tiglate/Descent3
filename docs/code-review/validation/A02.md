# A02: coverage extension (Linux Debug batch 1)

## What ran

clang-tidy 18.1.3 ran with the baseline check set over **every first-party
translation unit** in the Linux Debug compilation database: 387 of 387 sources,
excluding `third_party/` and generated build files. This is up from 16 in the
original sample. Every invocation exited 0; none failed or timed out. Headers
under the repository root were included and deduplicated by location.

The machine-readable record is [a02-linux-debug.json](../a02-linux-debug.json).
It holds per-module translation-unit counts, failures, diagnostic counts per
check family, and every analyzer finding, each flagged with whether it appeared
in the original sample. The raw logs are in the ignored `build/code-review/a02/`.

## Results

| Family | Unique diagnostics |
| --- | --- |
| bugprone | 8,792 |
| modernize | 2,809 |
| analyzer (gating family) | 1,483 |
| performance | 162 |
| readability / misc | 13 |

Of the 1,483 analyzer findings, 1,448 lie outside the original sample.
1,201 are `insecureAPI.strcpy` and 199 are `DeadStores`; these are bulk
hygiene patterns. The remaining **83** findings are the triage queue for batch 2:

- 21 NullDereference
- 11 unix.Malloc
- 9 CallAndMessage
- 8 NonNullParamChecker
- 7 uninitialized.Assign
- the rest are UndefinedBinaryOperatorResult, BitwiseShift, ArraySubscript,
  VirtualCall and UninitializedObject

By module, the queue is Descent3 36, netgames 24, ui 6, bitmap 3, sndlib 3,
and 11 elsewhere.

These are analyzer candidates, not confirmed bugs. No triage was performed in
this batch.
