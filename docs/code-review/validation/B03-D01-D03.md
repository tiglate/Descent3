# B03, D01, D02, D03: small correctness and cleanup items

## B03: pilot preview rotation

`(65535 / 360)` truncated to 182 in integer arithmetic before the float
multiply. The engine uses 65536 angle units per revolution, so the preview now
uses `65536.0f / 360.0f`. The identical expression in the TelCom ship preview
(`TelCom.cpp`) was changed the same way.

Expected heading units per frame, after the conversion to the 16-bit `angle`
argument:

| Elapsed | Old | New | Exact |
| --- | --- | --- | --- |
| 1/60 s | 91 | 91 | 91.02 |
| 1/30 s | 182 | 182 | 182.04 |
| 0.1 s | 546 | 546 | 546.13 |
| 0.5 s | 2730 | 2730 | 2730.67 |
| 1.0 s | 5460 | 5461 | 5461.33 |

At frame-rate time steps the rotation passed to the renderer is identical, so
the preview cannot look different. A visual check would show nothing, and none
was performed. Per-frame truncation to `angle` remains; it is unchanged legacy
behavior.

## D01: permanently disabled blocks

The two `#if 0` blocks named by the item were removed: the `select()` probe in
`nw_DoReceiveCallbacks` and the UI focus box in `UIWindow::Render`.
`nw_DoReceiveCallbacks` reads from a non-blocking socket until `recvfrom`
reports it would block, and its comment now says so.

The Debug preprocessed output of `networking.cpp` and `UIWindow.cpp` is
byte-identical before and after, apart from `__LINE__` values. `#if 0` is
platform-independent, so no configuration can be affected.

Remaining inventory, left for separate review as the item requires:

- `physics`: 3 blocks in 2 files (`collide.cpp` lines 2250 and 2317,
  `findintersection.cpp` line 3955)
- `editor`: 56 blocks in 10 files (Windows-only)

## D02: unused network scaffolding

`nw_LoadThreadLibrary` was already removed in M01. `MAX_CONNECT_TRIES` was a
file-local `#define` with no reference anywhere in the repository; it has been
removed. A preprocessor macro in a `.cpp` produces no symbol, so it cannot
affect exports, Windows linking or module loading.
