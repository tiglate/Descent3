# A01: incremental analyzer gate

The gate is a local command (`python3 tools/code_review/gate.py`) and an optional
`code_review_gate` CMake target suitable for calling from automation; this
repository currently has no CI workflow. It runs
the gate tests, a pinned clang-tidy 18.1.3 scan, and the comparison in sequence.
The sample remains the original 16 Linux Debug translation units and the
comparison gates analyzer diagnostics only; the other scanned checks are advisory.

`test_gate.py` constructs an isolated temporary source tree and compilation
database. A clean program passes a real scan and comparison. A null dereference
then produces an actual `clang-analyzer-core.NullDereference` warning and makes
the comparison fail. The test pins an actual diagnostic in a temporary Git
repository, checks that an inserted line still passes, then replaces the warning
with the same message in another function and verifies that comparison fails. A
missing baseline revision also fails closed. A synthetic third-party warning in a log is excluded. A
compiler error, a recorded timeout, and missing scan results all fail comparison.
An early scan failure removes previous results. The test also exercises an
out-of-tree build directory. `test_scan.py` verifies Debug selection from reordered
multi-config entries and requires a matching CMake build type for single-config
databases. Run all of them with:

```sh
rtk proxy python3 -m unittest discover -s tools/code_review -p 'test_*.py' -v
```

The comparison maps unchanged lines in both directions and refuses ambiguous
pairings. It is conservative: an unchanged diagnostic near complex edits can need
review; conversely, moved identical source blocks can still be matched incorrectly.
It reads source from the baseline Git revisions, which must be present locally.
The original
baseline is a Linux Debug sample, not a Windows or Release baseline. If a source
has multiple compile commands in the selected configuration, the first command
is used. The test for timeout uses a recorded timeout result rather than waiting
for an actual analyzer timeout. The integration test skips if clang-tidy 18.1.3,
`rtk`, or a C++ compiler is unavailable. Configure a fresh build database after
changing the build configuration or merging build changes before running the gate.

Three existing diagnostics surfaced when location matching replaced counts. They
are recorded with commit and rationale in `gate-baseline.json`: the INF symbol
copy is bounded by the 32-byte command buffer and a 260-byte destination; the
INF list-loop warning is a redundant assignment; the registry record copy is
preceded by the matching destination-size check. These are not blanket check
suppressions: each entry identifies one location and message.

On 2026-11-10, after the upstream merge, CMake regenerated the Linux Debug build
database and the local gate reported 42 existing analyzer findings and zero new
ones. The Debug engine and test targets built successfully; CTest reported 200
tests with zero failures, including one skipped opt-in real-GL test. This does
not replace the pending interactive and Windows checks recorded in other items.
